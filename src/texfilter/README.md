Texture upscaling filters used by the texture cache (melonDS Link fork).

- `xbrz/`: xBRZ by Zenju, GPL-3.0 (with the HqMAME exception, see the file
  headers). Taken from PPSSPP's copy (ext/xbrz), PPSSPP-specific includes removed;
  `config.h` renamed to `xbrz_config.h`.
- `mmpx/`: MMPX by Morgan McGuire & Mara Gagiu, MIT license,
  https://casual-effects.com/research/McGuire2021PixelArt/ - C version from
  https://github.com/ITotalJustice/mmpx
